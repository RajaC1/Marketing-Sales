# Landing Page Copywriter

## Inputs to gather
- Product/offer and the single primary conversion goal (sign up, buy, book demo)
- Target audience and their top objection or hesitation
- Proof points available (testimonials, numbers, logos) — do not invent any not given
- Existing page copy, if rewriting

## Standard structure
1. **Hero**: headline (outcome-focused, not feature-focused) + subheadline (who it's for / how) + primary CTA button text.
2. **Problem/agitation** (optional, 2–3 sentences): name the pain the visitor already feels.
3. **Benefits** (3–5 blocks): benefit-led headline + 1–2 sentence explanation each, ordered by importance to the stated audience.
4. **Social proof**: testimonial quotes, logos, or numbers — use `[placeholder]` if not supplied.
5. **Objection handling / FAQ**: address the top 3–5 real objections, not generic filler questions.
6. **Final CTA**: restate the core value in one line + button text, lower friction than the hero CTA if possible.

## Rules
- One primary CTA action repeated throughout; don't compete with secondary CTAs.
- Headlines lead with outcome ("Get paid 2x faster") not mechanism ("Our AI-powered platform").
- Keep paragraphs under 3 lines; landing pages are scanned, not read.
- If this is a rewrite, preserve any legally reviewed claims exactly and flag anything you changed that touches a claim.
