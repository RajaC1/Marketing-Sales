# Brand Voice Guide Builder

## When building a new guide
1. Ask for 3–5 samples of existing copy the user considers "on brand" (or ask them to describe the brand in a few adjectives).
2. Identify: sentence length/rhythm, formality level, vocabulary choices, use of humor/emoji, point of view (we/you/I), what the brand never says.
3. Produce a one-page guide with: 3 voice pillars (e.g., "confident, not arrogant"), a do/don't table with example phrasings, and a sample paragraph rewritten in-voice.

## When applying an existing guide
1. Read the guide the user provides (or the one previously generated).
2. Check any draft copy against each pillar and the do/don't table.
3. Rewrite flagged sentences and explain which rule they violated.

Never fabricate brand facts, taglines, or claims that weren't in the source material — flag gaps instead of inventing content.
