# SEO Content Brief Builder

## Inputs to gather
- Primary target keyword and any secondary/related keywords
- Business/product context (so the brief stays relevant, not generic)
- Any known top-ranking competitor URLs (if the user has them; otherwise work from stated intent)

## Brief structure
1. **Search intent**: informational / commercial / transactional / navigational — state which, and why.
2. **Target audience** and the specific question they're trying to answer.
3. **Recommended title + H1** (keyword near the front, still natural language).
4. **Outline**: H2/H3 structure with a one-line note on what each section must cover.
5. **Must-include elements**: definitions, comparison tables, FAQs, internal link targets, schema markup opportunities (FAQ, HowTo, Product).
6. **Word count guidance** based on stated competitive intensity (default: 1200–1800 for informational, 600–900 for commercial/product pages).
7. **Meta title (≤60 chars) and meta description (≤155 chars)** draft.

## Rules
- Never claim to know current live SERP rankings or competitor content unless the user supplied it — ask, don't guess.
- Optimize for the searcher's question first; keyword placement is secondary and must read naturally.
- Flag keyword cannibalization risk if the user has similar existing pages they mention.
